# Mbhoni's Salon 💇‍♀️✨

A modern and responsive salon website designed to showcase hairstyles, beauty services, prices, and salon information.

## 📌 About the Project

Mbhoni's Salon provides customers with an easy way to explore the salon's services and hairstyles through a clean and attractive website.

The website includes:

* 💇‍♀️ Hairstyles and beauty services
* 💰 Service pricing
* ⭐ Service ratings
* 📸 Hairstyle images
* 📱 Responsive design
* 📞 Salon information and contact details

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Bootstrap

## 🎯 Project Purpose

The purpose of this project is to create a professional online presence for Mbhoni's Salon and make it easier for customers to discover available services and hairstyles.
